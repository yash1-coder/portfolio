# Yash Chourasia — portfolio

Live site: https://portfolio-nine-delta-06dkumulcf.vercel.app

A static site generated by a small dependency-free Node script. There's no framework and nothing to install from npm: the output is plain HTML, CSS and a little vanilla JS, with all charts and diagrams rendered at build time.

```
src/content.js        ← all professional content and metrics (edit this)
src/case-studies.js   ← case-study page narratives
src/home.js           ← homepage sections
src/layout.js         ← <head>, metadata, header, footer
src/components.js     ← charts, flow diagrams, icons, illustrative dashboard
src/site.css          ← design tokens + styles (light/dark)
src/site.js           ← theme toggle, mobile nav, filters, tabs, skill explorer, lightbox
assets/               ← images (WebP), CV PDF, OG image, favicon
build.mjs             ← renders everything into dist/
tests/check.mjs       ← link, anchor, image, alt-text, metadata and content guardrail checks
CONTENT_AUDIT.md      ← where every claim comes from and what was corrected
```

## Commands

```bash
npm run build   # node build.mjs → dist/
npm test        # build + checks
npm run serve   # preview dist/ at http://localhost:4173
```

Requires Node 20+. Vercel runs `node build.mjs` and serves `dist/` (see `vercel.json`).

## Updating content

- **Text, dates, metrics, skills, links**: edit `src/content.js`. Each skill lists where it was used, which drives the skill explorer.
- **Replace the CV**: overwrite `assets/Yash_Chourasia_CV.pdf`, keeping the same filename.
- **Add a project card**: add an entry to `projects` in `src/content.js`. Use `featured: false` for a small card.
- **Add a full case study**: also add a render function and an entry to `caseStudies` in `src/case-studies.js`.
- **Images**: put WebP files in `assets/img/` and reference them as `/img/...`.
- Run `npm test` before pushing. The tests fail if previously removed, unverified claims reappear (see `tests/check.mjs`).

Only add figures that can be traced to a source, and record that source in `CONTENT_AUDIT.md`.

## Deploying

Pushing to `main` deploys production through Vercel's Git integration. Other branches get preview deployments.

## Rollback

- **Fastest**: in the Vercel dashboard, open Deployments → pick an earlier production deployment → **Promote to Production**.
- **Git**: the pre-redesign site is tagged `pre-redesign-2026-11`. To restore it:
  `git checkout main && git revert --no-edit <redesign-merge-commit>..HEAD && git push` (or `git revert -m 1 <merge-commit>`).
